## Minimal manifest

The smallest valid GPARS manifest. Declares an agent identity and an empty list of required capabilities.

```json
{
  "id": "org:example/agent:minimal-v1",
  "required_capabilities": []
}
```

## Coding assistant

A coding agent that needs workspace access, command execution, and version-control workflows.

```json
{
  "id": "org:example/agent:coding-assistant-v1",
  "version": "0.1.0",
  "required_capabilities": [
    {
      "id": "workspace_files",
      "description": "Inspect and modify files in the active workspace."
    },
    {
      "id": "command_execution",
      "description": "Run local commands needed for builds, tests, and development tasks."
    },
    {
      "id": "version_control",
      "description": "Inspect repository state and create local commits."
    }
  ],
  "optional_capabilities": [
    {
      "id": "browser_access",
      "description": "Open and inspect local or external web pages for development workflows."
    }
  ]
}
```

## Research assistant

A research agent that needs web research and file storage, with an optional cache for results. Includes extension metadata for research-specific configuration.

```json
{
  "id": "org:example/agent:research-assistant-v1",
  "version": "0.1.0",
  "required_capabilities": [
    {
      "id": "web_research",
      "description": "Navigate web sources and read retrieved research material."
    },
    {
      "id": "research_storage",
      "description": "Store and retrieve notes, citations, and intermediate research outputs."
    }
  ],
  "optional_capabilities": [
    {
      "id": "result_cache",
      "description": "Cache retrieved research results in an external database."
    }
  ],
  "extensions": {
    "org.example.research": {
      "max_search_depth": 3,
      "preferred_sources": ["arxiv", "scholar"]
    }
  }
}
```
